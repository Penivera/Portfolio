03

When migrating an air-gapped application server cluster in the DMZ to Linux, you face raw hypervisor reality: strictly static internal IPs, no DHCP, zero internet inside the VM, and isolated console clipboards preventing copy-pasting YAML into vim-tiny. You can't run apt install vim, and YAML indentation errors are fatal.

The breakthrough: I wrote the Netplan config locally, uploaded it to the hypervisor host, burned it into a virtual ISO image, and attached it as a bootable CD-ROM to the live Linux VM in vSphere. Mounted the disk, extracted the file, ran netplan try, and watched Cloudflare ICMP replies flood in.

Then I migrated 3 more servers to Linux without ever breaching the DMZ, configured dual-IP multi-homing to isolate inbound vs outbound traffic against DDoS, routed edge traffic from the Windows bastion through Sophos firewall to Traefik, and orchestrated automated internal deployments via Coolify.

Open Source / Rust + TypeScript + Compilers Pull Request #30723

CCXT - Rust Engine Decoupling & Transpiler Concurrency Architecture

Major architectural and performance overhaul of the Rust engine and TypeScript transpilation pipeline for CCXT, the industry-standard cryptocurrency trading framework (34k+ stars on GitHub). Decoupled the core runtime engine into a dedicated crate, eliminated recompilation overhead across ~200 generated exchange venues, and resolved catastrophic runner out-of-memory terminations on high-core runners.

  • Engine Decoupling: Extracted hand-written core runtime (Value, Exchange, OrderRouter, Precise, WebSocket primitives) into rust/ccxt-core. Refactored rust/ccxt-base to re-export it with zero breaking changes for ~200 venues.
  • Iteration Speedup: Drastically accelerated internal developer check and test cycles by skipping monolithic recompilation of ~200 venue modules during engine work.
  • OOM Elimination: Capped default transpile worker child-process fan-out to Math.min(4, os.availableParallelism()), eliminating runner OOM terminations and swap thrashing on high-core machines.
  • Worker Lifecycle & AST Cache: Added explicit destroy() cleanups for piscina worker thread heaps across C#, Go, and Java transpilers, plus cached program batches in worker-program-batch.ts to prevent LRU thrashing.
  • Linker Optimization: Integrated automated high-performance linker detection (mold → lld) in cargo runner tooling.
Rust TypeScript Node.js Worker Threads AST Transpilers Piscina Pool mold / lld High Concurrency

Enterprise Infrastructure / VMware ESXi + Linux DMZ Cluster + Traefik + Sophos + Coolify Production Datacenter

JRB & AKIRS Enterprise Datacenter, Linux DMZ Cluster Migration & Edge Routing Architecture

Engineered and administered the Akwa Ibom State (AKS) segment of the mission-critical tax revenue digital infrastructure and public-facing state portal (akirs.ak.gov.ng) deployed at Equinix Colocation Datacenter under the Joint Revenue Board (JRB) Programme, collaborating closely with the datacenter engineering team where and when necessary. Encompassed bare-metal compute clustering, four-tier VLAN network segmentation, an air-gapped 4-node Linux cluster migration, dual-IP DDoS mitigation, edge reverse proxy routing via Traefik, and automated deployment orchestration via Coolify.

  • Air-Gapped Virtual ISO Bootstrap: Overcame hypervisor clipboard isolation and strict static IP allocation (no DHCP, no internet in bare VM, no package managers) by authoring Netplan network definitions offline, synthesizing a bootable virtual ISO image, mounting it as a virtual CD-ROM drive in VMware vSphere, extracting the configuration, and binding static IP with verified Cloudflare ping.
  • 4-Node Application Cluster Migration to Hardened Linux: Migrated all 4 application servers in the cluster from legacy Windows Server to Linux without ever moving them out of the secure, isolated DMZ (VLAN 20).
  • Dual-IP Multi-Homed DDoS Mitigation: Configured edge Linux instances with two distinct IP addresses: one dedicated exclusively for inbound traffic and one dedicated for outbound egress, isolating attack surfaces, mitigating connection state exhaustion, and preventing DDoS compromise.
  • Sophos Firewall to Bastion & Traefik Edge Routing: Routed incoming edge traffic through the Windows bastion server via Sophos XGS firewall NAT rules into an edge Linux VM acting as an internal reverse proxy running Traefik.
  • Public-Facing State Portal & High Availability: Maintained high-availability edge routing, TLS reverse proxy mappings, and infrastructure powering the official Akwa Ibom State revenue portal (akirs.ak.gov.ng) for statewide citizen tax services and revenue collection.
  • Automated Container Deployment with Coolify & RBAC: Orchestrated containerized Docker services using self-hosted Coolify via internal static IPs and encrypted SSH keypairs, exposing granular least-privilege user permission sets.
  • Hypervisor & Compute Cluster: Clustered dual HPE ProLiant Gen10 compute nodes running VMware ESXi 8.x managed centrally through VMware vCenter Server Appliance (vSphere Client) with dynamic compute resource pools and live VM vMotion migrations, collaborating with the datacenter engineering team where and when necessary.
  • 4-Tier Network Segmentation: Segmented infrastructure across four dedicated VLANs on Cisco Catalyst 1300 switches: VLAN 1 (MGMT), VLAN 10 (LAN), VLAN 20 (DMZ), and VLAN 30 (Storage - isolated, non-routed backup fabric).
  • Storage, Backup & DR Pipeline: Configured enterprise Synology NAS in RAID 5 with NVMe SSD cache, interconnected via isolated VLAN 30 directly to Veeam Backup Appliance (BCKUP-SRV01) with verified non-destructive full-VM instant disaster recovery restore drills.
  • WAN Redundancy: Integrated high-speed Starlink Satellite Internet terminal as an active WAN failover for primary Equinix colocation fiber links, including obstruction mapping, PoE routing, and automated failover routing.
